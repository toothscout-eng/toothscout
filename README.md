# ToothScout phased launch website

Static GitHub Pages website.

## Publish
1. Upload all files to the root of a public GitHub repository.
2. Settings > Pages > Deploy from branch > main > root.
3. Add `toothscout.com` as the custom domain.
4. Configure DNS in Cloudflare as instructed by GitHub Pages.
5. Enable HTTPS after DNS resolves.

## Before public launch
- Replace placeholder SVG marks with the approved ToothScout production logo assets, preserving filenames.
- Replace `hello@toothscout.com` if required.
- Add the dedicated business telephone and WhatsApp number.
- Finalise and legally review privacy, terms, marketplace contracts, verification wording, payment flow, VAT treatment and employment-status positioning.
- The launch forms currently prepare an email and do not store data. Connect to a compliant backend later.
- Update the Phase 1 progress indicator manually in `index.html` and `styles.css`; no public number is displayed.

## Important operating claim
Only publish “verified” claims once the documented checks are operational and completed before a dental nurse becomes available through ToothScout.
